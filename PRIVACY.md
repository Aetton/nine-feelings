# Конфиденциальность / Privacy

Девять чувств (Nine Feelings) — локальный дневник эмоций.

- Приложение хранит выбранные эмоции, время отметок, комментарии и настройки внутри своего закрытого каталога Android.
- Нет аккаунтов, рекламы, аналитики, трекеров и разрешения на доступ к интернету. Приложение не передаёт записи разработчикам или другим сервисам.
- Автоматическое облачное резервирование и перенос данных средствами Android отключены. Резервную копию создаёт сам пользователь через системный выбор файла.
- Копия — незашифрованный JSON-файл. Если выбрать облачного поставщика в системном выборе файла, файл будет обработан выбранным поставщиком по его правилам. Приложение не управляет этим сервисом.
- Импорт добавляет отсутствующие записи, не перезаписывает существующие комментарии и восстанавливает набор кнопок из копии.
- Отметки можно удалять в приложении. Очистка данных Android или удаление приложения удаляет локальный дневник. Сохранённые отдельно копии нужно удалять отдельно.
- Шифрование данных на устройстве и блокировка доступа определяются средствами Android. Отдельного пароля или шифрования файлов внутри приложения нет.
- Дневник предназначен для самостоятельного наблюдения, не ставит диагнозы и не является медицинским прибором.

The app stores emotion entries, timestamps, comments and preferences locally in Android's private app storage. It has no internet permission, advertising, analytics, accounts or tracking. Automatic Android backup and device transfer are disabled. Manual backups are readable, unencrypted JSON files; a cloud document provider is used only if the user explicitly selects it in Android's file picker. Uninstalling the app deletes local data, but does not delete separately exported files. Device encryption and screen locks are provided by Android, not by an app-specific password. This is a self-observation journal, not a medical device.
