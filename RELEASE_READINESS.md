## Что изменено для надёжности

- Постраничная история по 50 записей вместо создания всех карточек сразу.
- SQL-агрегация статистики без загрузки комментариев всего дневника.
- Фоновая запись из виджета; независимые таймеры подтверждения.
- Восстановление черновиков редакторов после пересоздания Activity.
- UUID записей, проверка входных значений, транзакционные копии и восстановление.
- Потоковый экспорт с ограничением размера, чтобы не строить весь файл в оперативной памяти.
- Явное отключение автоматического облачного backup и device transfer.
- Лицензия MIT, исходники и изображения с понятным происхождением; документация конфиденциальности внутри приложения и репозитория.
- Стандартная сборка, закреплённые инструменты и действия CI, приватный ключ вне исходников.

## Ограничения перед публичным распространением

1. **Физические телефоны и сторонние лаунчеры ещё не проверены.** Нужен короткий пилот: добавить/изменить размер виджета, перезагрузить телефон, оставить приложение в фоне и проверить запись/карточку. Не заявляется совместимость со всеми OEM-ограничениями фоновой работы.
2. **73 предупреждения Lint не скрыты baseline-файлом.** Это русские строки непосредственно в XML, мелкий текст компактного виджета, вложенные веса, RTL и атрибуты с альтернативами для старых Android, а также уведомление о новой версии инструментов. Ошибок Lint нет. Полная локализация и аудит TalkBack/крупного шрифта не завершены.
3. **Резервные копии не зашифрованы**, ограничены 16 МиБ / 100 000 записей. При выборе облачного провайдера файл передаётся ему пользователем. Восстановление всей повреждённой базы без исправной JSON-копии не реализовано; повреждённый файл сохраняется.
4. **Подпись публичного релиза отличается от прототипа.** Preview APK совместим со старой тестовой подписью, release APK — с новым приватным ключом. Перед переходом со старой установки нужно экспортировать дневник. Не удалять прототип без копии.
5. **F-Droid ещё не принял приложение.** Репозиторий и рецепт подготовлены; необходимы опубликованный релизный тег, `fdroid lint` / `fdroid build` и рассмотрение сопровождающими. Это не заменяется успешной Docker-сборкой. Требование периода разработки/исключений проверяется при подаче.
6. **Ключ релиза необходимо безопасно скопировать до публикации.** Ключ и пароль находятся вне репозитория, не в исходном ZIP. Их потеря осложнит или исключит совместимые обновления собственной APK-раздачи.
