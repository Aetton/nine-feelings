# Contributing

Keep the app offline, small and accessible. Preserve immutable historical emotion revisions and user progress across every schema change. Do not add network permissions, telemetry or closed SDKs.

Use Java 17 and the checked-in Gradle wrapper. Android SDK 36 and Build Tools 35 are required. Build commands are in README.md. Resources generated by `generate-resources.cjs` are checked in; Node.js is required only when changing the generator. Include the regenerated XML in changes.

Before proposing a change, run `sh gradlew assembleDebug assembleRelease bundleRelease lint` and `sh gradlew connectedDebugAndroidTest` on a running emulator. Tests must use isolated databases. Test migrations from every supported previous schema and backup round trips for persistence changes. Never include real diary contents, private keys, passwords, local SDK paths or exported backups in a patch.

Report bugs with Android version, launcher, widget size, reproduction steps and a screenshot with private information removed. Do not attach a diary database or backup to a public issue. Contributions are provided under the project's MIT license.
